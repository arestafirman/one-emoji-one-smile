## The entry

👐 — OPEN HANDS SIGN (U+1F450).

Two open hands: a gesture of welcome and embrace, the kind of warmth a
stranger reads at first glance with no context needed. Friendly without
being intimate, gentle without irony, the same in any age or background —
and a deliberate pick, not the first smiley that comes to mind.

## How it works

`main.ts` is a dependency-free Node TypeScript program. It creates
`/output` if needed and writes exactly that one emoji to
`/output/entry.txt` — UTF-8, 4 bytes (`f0 9f 91 90`), no trailing
newline, deterministic, fully offline, no randomness, no clock reads.

Run it with:

```sh
node main.ts
```
